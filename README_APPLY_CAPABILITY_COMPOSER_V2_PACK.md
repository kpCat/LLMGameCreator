# LLMGameCreator Capability Composer v2 Pack

Purpose: add source-of-truth docs and executable Codex task specs for moving from the current flat Capability Picker toward a composable game design workflow without burning Codex tokens on broad exploratory documentation.

Apply:
1. Unzip at repository root.
2. Review files under `docs/`.
3. Choose exactly one implementation task from `docs/agent-tasks/NEXT_PRODUCT_SLICE/`.
4. Give Codex only the chosen task spec, not the whole pack.

Recommended first code task:
- `docs/agent-tasks/NEXT_PRODUCT_SLICE/001_CAPABILITY_PICKER_HELP_AND_COMPATIBILITY_UI.md`

This first task intentionally avoids rewriting the whole selection model. It improves immediate usability and creates a safe bridge toward Capability Composer v2.

Do not implement every task in one Codex run.
