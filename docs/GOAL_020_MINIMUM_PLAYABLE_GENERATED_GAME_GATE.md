The final gate must remain `required`, not `passed`.

## Purpose

Goal 019 made the Unity Alpha readable enough for manual play review.

Goal 020 must package the current generated Alpha evidence into the first minimum playable generated game review gate.

This is the milestone where the user should be able to launch a Windows player and play one short generated scenario from start to completion without reading JSON.

This goal must not pretend that the full generator is complete. It must produce a review-ready minimum game slice with:

- selected generated scenario identity;
- readable presentation;
- movement/focus/interact controls;
- generated quest objective checklist;
- generated dialogue/item/event loop;
- completion and reward;
- launch instructions;
- automated launch/play-loop proof;
- manual review checklist.

The user-visible result should be:

```text
Open one folder, run one exe, play one generated scenario to completion, and review a short checklist.
```
