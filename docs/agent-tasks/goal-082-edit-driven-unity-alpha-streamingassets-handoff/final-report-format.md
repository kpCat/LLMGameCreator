# Final report format

Final report must include:

- Final status: GREEN / BLOCKED / FAILED.
- Latest commit before work and after work.
- Push status to `origin/main`.
- Preflight summary: branch, origin/main, Goal 081 handoff, Goal 080/081 artifact status, AlphaRuntimeBootstrap baseline.
- Changed files grouped by area.
- Implemented behavior.
- Unity handoff payload summary: files, hashes, StreamingAssets relative root, source artifacts consumed.
- Unity probe summary: exact Unity files changed/added and why `AlphaRuntimeBootstrap.cs` remained unchanged.
- Package read proof, simulated Unity probe proof, command/transcript proof, negative proof.
- WinForms binding proof.
- Quality gate metrics: source scan count, max line length, files over 1000, minified count, zero-LF/CR-only counts, parent page lines, AlphaRuntimeBootstrap before/after hash and line count.
- Validation results with pass/fail counts.
- Artifact-scope result.
- Evidence hygiene result.
- Remaining P2/P3 debt.
- Final git status.
- Git commands used and why.
- Goal usage if available.
