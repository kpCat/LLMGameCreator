# Final report format

Report exactly these sections:

1. Final status: GREEN / BLOCKED / FAILED.
2. Latest commit before work.
3. Latest commit after work.
4. Push status to `origin/main`.
5. Preflight summary:
   - branch;
   - current top commit;
   - Goal 078 artifact status;
   - Goal 078 handoff recorded before Goal 079;
   - forbidden-area baseline.
6. Changed files grouped by area.
7. Implemented behavior:
   - Application seam;
   - WinForms dashboard/control binding;
   - cross-goal artifact chain audit;
   - negative proof index;
   - acceptance readiness output;
   - quality debt classification.
8. Proof metrics:
   - Goal 074-078 report hashes consumed;
   - chain item count;
   - blocker count;
   - P0/P1/P2/P3 counts;
   - parent workspace line count;
   - max C# line length;
   - minified source count;
   - files over 1000 lines;
   - AlphaRuntimeBootstrap line count/hash/no-change status.
9. Validation results with pass/fail counts.
10. Artifact-scope result.
11. Evidence hygiene result.
12. Remaining debt.
13. Final git status.
14. Git commands used and why.
15. Goal usage if available.
