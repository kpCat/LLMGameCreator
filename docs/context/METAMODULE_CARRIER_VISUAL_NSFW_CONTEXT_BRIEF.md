# Metamodule Carrier Visual / Adult Content Context Brief

## Status

Context brief / anti-forgetting note.

This brief captures the user's intended visual direction for a possible generated game family such as "Носитель Метамодулей". It should guide future task shaping, documentation and architecture discussions. It is not an implementation task by itself.

## Game direction

"Носитель Метамодулей" is expected to support rich fantasy/sci-fi worlds with a large set of unique species, possibly around 100 different creature/people archetypes.

The target is not text-RPG-only. The target is visually rich 2D / 2.5D / pseudo-3D games with:

- generated worlds;
- landscapes and scenes;
- characters and species presentation;
- clothing/equipment states;
- wounds and body/clothing condition states;
- pseudo-3D or layered 2D presentation;
- optional adult/NSFW presentation where enabled by project policy.

## Important user intent

The user wants graphics to be composable and beautiful, not brute-force generated by an LLM one picture at a time.

The intended direction is:

```text
semantic visual packs
+ reusable part families
+ palettes
+ layer stacks
+ deterministic generators
+ seeds
+ reviewable AI refinement where useful
```

Codex should implement generators, validators and contracts. Codex should not dump thousands of art records or generate final art assets.

## Adult/NSFW direction

Adult/NSFW visuals are an important possible layer for some generated games.

The adult layer should support:

- adult sapient fantasy species;
- human-compatible humanoid body plans where lore allows it;
- male, female, and mixed/androgynous sex-presentation variants;
- safe and adult variants of the same species;
- adult-only nude/anatomy reference slots;
- adult relationship scene slots for reviewed adult builds;
- rating-gated export behavior.

The adult layer must be treated as an extension of the normal visual composition pipeline, not as a separate image generator.

## Mandatory boundaries

Adult visual slots require:

```text
adult project flag
+ adult character flag
+ sapient species
+ humanoid/humanoid-compatible body plan
+ safe fallback
+ review/promotion
```

Reject or quarantine:

- minors or age-ambiguous subjects;
- teen/childlike/young-looking cues;
- feral or non-sapient sexualized creatures;
- non-consensual framing;
- adult assets in safe/public builds;
- unreviewed provider output;
- prompt tags that conflict with policy.

## Visual composition target

For each species, prefer a Creature Visual Genome instead of a one-off image prompt.

A species should define:

- body plan;
- silhouette;
- surface materials;
- color/palette families;
- appendages such as horns, wings, tails, spines, claws;
- sex-presentation profiles;
- clothing slots;
- equipment slots;
- state overlays;
- projection modes;
- adult slots and restrictions;
- forbidden combinations.

## Character state axes

The visual system should eventually support:

- normal clothing;
- armor/equipment;
- damaged clothing;
- wet/dirty/bloody states;
- wounds and exhaustion;
- transformation/corruption states;
- relationship/suggestive states;
- adult-only presentation states.

These should be data-driven and layered where possible.

## Role of ComfyUI/Civitai

ComfyUI, Civitai models and other image tools are offline provider/refinement aids.

They may be useful for:

- master art;
- hero scenes;
- reference sheets;
- creature body-plan concepts;
- reusable part packs;
- adult-only reviewed candidate art;
- image-to-image refinement from deterministic masks/control images.

They must not become Runtime dependencies and should not be called from Unity Player.
