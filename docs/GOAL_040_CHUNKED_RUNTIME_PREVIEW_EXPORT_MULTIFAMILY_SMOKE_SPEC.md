# Goal 040 — Chunked Runtime Preview/Export Multi-Family Smoke Specification

## Goal

Create the next aggressive product slice after Goal 039 by consuming runtime chunk traversal/delta evidence into a bounded preview/export/generated-loop consumer path.

This goal combines the intent of the existing queue items:

- Goal 040: Chunked Runtime Preview Or Export Consumption
- Goal 041: Multi-Family World Scale Runtime Regression
- Goal 042: Infinite/Chunked World Smoke

The implementation must not be only a report. It must create a deterministic consumer seam that takes Goal 039 runtime chunk traversal proof and produces preview/export-compatible payload artifacts, multi-family regression evidence, and an infinite/chunked smoke proof.

## Gate

```text
chunked_runtime_preview_export_multifamily_smoke_verification required
```

## Non-goals

- No broad streaming/runtime refactor.
- No WinForms UI editing.
- No Unity entrypoint editing.
- No GamePackage schema mutation.
- No provider/LLM/RAG calls.
- No Lua execution changes.
- No generator-library changes.
- No new external dependencies.

## Expected product value

After this goal, the repository should prove that generated world/chunk traversal is no longer isolated evidence. It should flow into a bounded consumer route that can later feed Runtime Preview/Unity/export without forking world/chunk architecture.

## Required proof

The report must prove:

- Goal 039 was accepted by user handoff before Goal 040 work.
- Goal 040 did not mark its own gate passed.
- At least four scenario payloads were consumed.
- At least three generated-family lenses reuse the same chunk traversal path.
- The consumer path uses Goal 039 runtime chunk deltas, not only Goal 038 static map facts.
- Save/load or state-roundtrip proof from Goal 039 remains correlated to the consumer payload.
- Chunk traversal commands, visited/discovered/checkpoint/landmark/mutation/replay concepts are preserved in the consumer payload.
- Package definitions remain immutable.
- No broad Runtime/UI/Unity/GamePackage/schema/provider/LLM/RAG/Lua/generator-library mutation was required.
- Invalid/fake/leak matrix is causal and machine-checkable.
