# .devflow — Autonomous Development Pack для LLMGameCreator

Назначение каталога: дать локальному агенту рабочие рельсы для автономной разработки без ручного составления каждой следующей задачи.

Это не новый production-модуль и не часть runtime. Это операционный слой для разработки:

- выбор следующей задачи;
- чтение только релевантных документов и файлов;
- ограниченное изменение кода;
- build/test/simulation gates;
- отчётность;
- stop conditions;
- контроль, чтобы агент не ушёл в самовольный рефакторинг.

| Файл | Назначение |

| `STOP_CONDITIONS.md` | Условия немедленной остановки. |

| `MODELING_STRATEGY.md` | Как моделировать pipeline без реальных LLM-вызовов. |
| `CURRENT_RUN.md` | Журнал текущего запуска агента. |
| `NEXT_TASK.md` | Следующая разрешённая задача. |
| `BLOCKERS.md` | Блокеры, требующие решения пользователя. |
| `RUN_REPORT_TEMPLATE.md` | Формат отчёта после каждой задачи. |

## Режим работы

По умолчанию агент выполняет одну задачу за запуск. Разрешение на 2-3 задачи подряд можно дать только после нескольких успешных прогонов.

Запрещён режим “делай всё до конца без остановок”. Вместо этого используется bounded loop:

```text
read state -> select task -> plan -> patch -> build -> test -> simulate -> report -> stop/continue
```

Если срабатывает любое условие из `STOP_CONDITIONS.md`, агент обязан прекратить изменения и записать блокер.
